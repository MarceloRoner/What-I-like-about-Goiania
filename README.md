# 🌆 O que eu mais gosto em Goiânia

Este é um site simples e pessoal que compartilha alguns dos meus locais favoritos em Goiânia, como parques, bares e lugares icônicos da cidade. O objetivo do projeto é praticar HTML e CSS, enquanto apresento um pouco da cultura e gastronomia local.

## 🖥 Tecnologias Utilizadas

- **HTML5**: Estrutura da página
- **CSS3**: Estilização da página
- **Git/GitHub**: Controle de versão e publicação no GitHub Pages

## 🌍 Acesse o Site

O site está hospedado no **GitHub Pages** e pode ser acessado pelo seguinte link:
🔗 [Acesse aqui](https://marceloroner.github.io/What-I-like-about-Goiania/) 

## 📂 Estrutura do Projeto

```
/
├── index.html       # Página principal
├── style.css        # Estilos do site
├── imagens/         # Imagens no diretório principal
├── README.md        # Este arquivo
└── .gitignore       # Arquivos ignorados no repositório
```

## ⚙️ Como Executar Localmente
Caso queira rodar o site localmente, basta seguir os passos abaixo:

1. Clone o repositório:
   ```bash
   git clone https://github.com/SeuUsuario/SeuRepositorio.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd SeuRepositorio
   ```
3. Abra o arquivo `index.html` no navegador.
